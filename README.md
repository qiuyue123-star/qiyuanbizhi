起源壁纸一款 1.7 MB 的界面外观工具：原生 C++ 渲染的玻璃拟态壁纸生成器，外加一颗挂在状态栏顶部的灵动岛。

**详细介绍**

起源壁纸做的是两件相关但不相同的事 —— 把桌面变好看，把状态提示变好看。

壁纸侧是一套自研的「玻璃拟态引擎」，模糊、背板、光团、颗粒都由 `liborigin_glass`、`liborigin_rs`、`liborigin_core` 三个原生库在本地实时计算，不依赖云服务。生成时可选精简、均衡、完整三档渲染档位，并单独调节透明度、模糊强度、圆角与缩放比例，主题配色有「深空玻璃」和「跟随系统主题」两种取向 —— 后者完全沿用系统背景色、强调色与字体，不做覆盖。确认后一键写入系统壁纸。

灵动岛侧是在系统界面之上绘制的一层覆盖层：屏幕顶部正中央一枚黑色胶囊，由充电、断电、电量偏低、屏幕点亮、通知消息这几类事件触发展开，内容涵盖充电功率与预计充满时间、电量、媒体播放状态与通知摘要。胶囊可调收起尺寸，支持先预览再启用；关闭后不占用任何悬浮窗。它需要「系统 UI 覆盖层」权限，消息提醒另需通知监听权限；未授权时只监视充电与电量，不影响已经设好的静态壁纸。

还有一个挺特别的手势控制：开启后前置摄像头逐帧在内存里判断手掌姿态 —— 张开手掌开启灵动岛，握拳关闭。全程不录制、不保存、不上传，关掉开关即释放摄像头。此外支持导入第三方壁纸扩展包。

**核心功能**

- **玻璃拟态壁纸生成**：原生渲染，三档画质（精简 / 均衡 / 完整），可调透明度、模糊、圆角、缩放
- **主题适配**：深空玻璃 / 跟随系统主题（背景色、强调色、字体）
- **灵动岛**：顶部居中胶囊，充电、断电、低电量、亮屏、通知五类触发，玻璃拟态外观，展示电量、充电进度、媒体与消息
- **手掌手势控制**：前置摄像头本地识别，张开开启、握拳关闭，不录制不上传
- **功能扩展**：按需授权的数据型壁纸玩法 —— 实景素材、按地理位置匹配昼夜壁纸、按应用使用分布生成桌面布局、按联系人生成头像壁纸、按通话频率生成常联壁纸、按短信生成信息流壁纸、随步数调整动态粒子、随心率调整光效节奏
- **权限中心**：一键申请全部权限，逐项显示状态；系统级能力（root / 平台签名）只做只读检测，不执行任何提权动作
